## Hızlı Kurulum

1. CS2 görüntü ayarlarından ekran modunu **Tam Ekran Pencereli (Fullscreen Windowed)** seçin.
2. [yunalcore.app/tr/cs2-bedava-hile](https://yunalcore.app/tr/cs2-bedava-hile) üzerinden kayıt olup Loader'ı indirin — ilk girişte 24 saatlik deneme otomatik açılır.
3. Oyun içinde **`Insert`** tuşu ile menüyü açın, hazır ayarlar için [Configler](https://yunalcore.app/tr/configs) sayfasındaki kodları kullanın.
